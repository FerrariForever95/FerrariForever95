## About

I'm an embedded systems engineer working across the full stack of hardware and software products — from PCB design and microcontrollers to firmware, device drivers, operating systems, graphical interfaces, IoT platforms, and cloud services.

I enjoy working close to the hardware: understanding how a system works at the register and peripheral level, designing the electronics, writing the firmware, developing the software architecture, and connecting the finished device to the outside world.

My interests include **embedded systems, operating systems, kernel development, low-level C programming, hardware/software co-design, IoT, robotics, and connected devices**.
