## 🚀 Featured Highlight: Zeno OS

### **Native C-Kernel Embedded Operating System for ESP32-S3**

**Zeno OS** is a custom-built, research-oriented embedded operating system designed specifically for the ESP32-S3. It serves as an exploration into native kernel design, constrained hardware resource management, and rich graphical rendering on low-power microcontrollers.

* **Kernel Architecture:** Custom C-kernel implementing thread scheduling, process abstraction, memory management, and hardware initialization.
* **Device Drivers & Peripherals:** Low-level peripheral control, interrupt handling, and custom driver layers written from scratch.
* **Graphical Interface:** Native embedded graphical user interface (GUI) rendering system running directly on top of the custom kernel.
* **Research Documentation:** Formally detailed in a peer-shared academic paper.

📄 **[Read the Research Paper on ResearchGate](https://www.researchgate.net/publication/409852826_Zeno_OS_-_A_Native_C-Kernel_Embedded_Operating_System_with_a_Graphical_Interface_for_the_ESP32-S3)**
