My embedded development experience spans multiple generations and architectures of microcontrollers and single-board computers, including:

* **ESP8266** — Wi-Fi-enabled embedded and IoT applications
* **ESP32** — Wi-Fi/Bluetooth embedded systems
* **ESP32-S3** — native systems, kernel development, GUI and research
* **ESP32-C3** — RISC-V based embedded applications
* **ESP32-C6** — RISC-V, Wi-Fi 6 and modern IoT experimentation
* **STM32** — microcontroller and firmware development
* **AVR** — low-level embedded and 8-bit microcontroller development
* **Arduino** — rapid prototyping and embedded applications
* **Raspberry Pi** — Linux-based embedded, IoT and systems projects

### ☁️ Cloud & Connected Systems

I also work on **IoT and cloud-connected embedded systems**, bridging devices and software infrastructure using **Google Cloud**.

```text
Sensors / Hardware
        ↓
ESP8266 / ESP32 / STM32 / AVR
        ↓
Firmware / Drivers / RTOS
        ↓
Connectivity
        ↓
IoT / Backend Services
        ↓
Google Cloud
        ↓
Applications & Data
```

This gives me experience across both sides of connected systems:

**Device → Firmware → Network → Cloud → Application**
