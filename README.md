## 🖥️ Zeno OS

<p align="left">
  <img src="https://img.shields.io/badge/Zeno_OS-Native_C_Kernel-222222?style=for-the-badge&logo=c&logoColor=white"/>
  <img src="https://img.shields.io/badge/ESP32--S3-E7352C?style=for-the-badge&logo=espressif&logoColor=white"/>
  <img src="https://img.shields.io/badge/Embedded_OS-8E44AD?style=for-the-badge"/>
  <img src="https://img.shields.io/badge/GUI-673AB7?style=for-the-badge"/>
  <img src="https://img.shields.io/badge/Research-8E44AD?style=for-the-badge"/>
</p>

**Zeno OS** is my research-oriented **native C-kernel embedded operating system for the ESP32-S3**.

The project explores operating-system concepts directly on microcontroller hardware, combining:

* Native C kernel development
* Low-level hardware control
* Memory management
* Scheduling
* Device drivers
* Peripheral management
* Embedded graphics
* GUI development
* Hardware/software integration

The goal is to explore how operating-system concepts can be designed and implemented for **resource-constrained embedded hardware**.

### System Architecture

```text
                 Zeno OS
                    │
        ┌───────────┴───────────┐
        │                       │
     Kernel                  Drivers
        │                       │
        ├──────────┬────────────┤
        │          │            │
    Scheduler   Memory      Peripherals
        │       Manager          │
        │          │             │
        └──────────┴─────────────┘
                    │
               GUI / Display
                    │
                    ↓
              Applications
                    │
                    ↓
               ESP32-S3
```
